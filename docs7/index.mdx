CSharpEssentials is a set of small .NET packages for writing C# in a functional style: results instead of exceptions, explicit optionals, unions and rules, plus ASP.NET Core, EF Core, Mediator and source-generated endpoint and service registration. Each package ships on its own, so you install only what you use.

## Installation

```bash
dotnet add package CSharpEssentials            # meta-package: Results, Errors, Maybe, Any, These, Rules, Core, Enums, Entity, Clone, Json, Http, Time
dotnet add package CSharpEssentials.Mediator   # any other package on its own
```

## Quick start

```csharp Program.cs
// dotnet add package CSharpEssentials
using CSharpEssentials.Errors;
using CSharpEssentials.Maybe;
using CSharpEssentials.ResultPattern;

Dictionary<string, decimal> prices = new() { ["book"] = 12.5m, ["pen"] = 1.2m };

foreach ((string product, int quantity) in new[] { ("book", 2), ("lamp", 1), ("pen", 0) })
{
    string line = PlaceOrder(product, quantity).Match(
        onSuccess: total => $"{product} x{quantity}: {total}",
        onError: errors => $"{product} x{quantity}: {errors[0].Code}");
    Console.WriteLine(line);
}
// book x2: 25.0
// lamp x1: Product.NotFound
// pen x0: Order.Quantity

Result<decimal> PlaceOrder(string product, int quantity) =>
    FindPrice(product)
        .ToResult(Error.NotFound("Product.NotFound", $"No product named '{product}'."))
        .Ensure(_ => quantity > 0, Error.Validation("Order.Quantity", "Quantity must be positive."))
        .Map(price => price * quantity);

Maybe<decimal> FindPrice(string product) =>
    prices.TryGetValue(product, out decimal price) ? price : Maybe.None;
```

## Core concepts

### Result and Error

An operation that can fail returns `Result` or `Result<T>`. A value or an `Error` converts to it implicitly. `Map`, `Bind` and `Ensure` stop at the first failure, and every member that takes an async lambda ends in `Async` (`BindAsync`, `MapAsync`).

```csharp
Result<User> GetUser(int id) =>
    users.TryGetValue(id, out User? user) ? user : Error.NotFound("User.NotFound", $"User {id} was not found.");
```

`Result<T, NotFoundError, ConflictError>` puts the error kinds in the signature, and ASP.NET Core turns it into a typed HTTP result. See [Results](/libraries/results) and [Errors](/libraries/errors).

### Maybe

`Maybe<T>` holds a value or nothing, without `null`.

```csharp
string email = FindUser(id)
    .Bind(user => Maybe.From(user.Email))
    .Map(e => e.ToLowerInvariant())
    .GetValueOrDefault("no email");
```

See [Maybe](/libraries/maybe).

### Any and These

`Any<T0, T1, ...>` is exactly one of several types. `Match` takes one handler per type. `These<TError, TValue>` adds a third state that carries an error and a value together, for partial success.

```csharp
Any<Order, OutOfStock> outcome = PlaceOrder(quantity);
string text = outcome.Match(order => $"ordered {order.Quantity}", stock => $"only {stock.Available} left").Result!;
```

See [Any](/libraries/any) and [These](/libraries/these).

### Rules and validation

Rules are functions or classes that return `Result`, combined with `And()`, `Or()` and `Linear()`. `Validator<T>` validates a model and returns `Result<T>` with one error per failed rule.

```csharp
internal sealed class CreateUserValidator : Validator<CreateUser>
{
    protected override ValueTask Configure(CreateUser model, RuleContext<CreateUser> rules, CancellationToken ct = default)
    {
        rules.For(() => model.Email).NotEmpty().EmailAddress();
        rules.For(() => model.Age).InclusiveBetween(18, 120);
        return ValueTask.CompletedTask;
    }
}
```

See [Rules](/libraries/rules) and [Validation](/libraries/validation).

### ASP.NET Core

Failed results become problem details responses with the status that matches the error type (404 for `NotFound`, 409 for `Conflict`, 422 for `Domain`).

```csharp
builder.Services.AddEnhancedProblemDetails();
builder.Services.AddExceptionHandler<GlobalExceptionHandler>();
// ...
app.UseEnhancedProblemDetails();
app.MapGet("/users/{id:int}", (int id) => LoadUser(id).ToHttpResult()); // 200 or a 404 problem, both in OpenAPI

static Result<User, NotFoundError> LoadUser(int id) =>
    id == 1 ? new User(1, "Ada") : new NotFoundError("user.not_found", $"User {id} was not found.");
```

See [AspNetCore](/libraries/aspnetcore).

### Endpoints and dependency injection

Source generators replace reflection scanning. An endpoint is a class with a static `Map` method, and a service is a class with a lifetime attribute. Both work with Native AOT.

```csharp
[EndpointGroup<TodosGroup>]
public sealed class ListTodos : IEndpoint
{
    public static void Map(IEndpointRouteBuilder app) => app.MapGet("/", (ITodoStore store) => store.All());
}

[RegisterScoped] // registered as ITodoStore
public sealed class TodoStore : ITodoStore { /* ... */ }

// Program.cs
builder.Services.AddAllServices();
app.MapAllEndpoints();
```

See [Endpoints](/libraries/endpoints) and [DependencyInjection](/libraries/dependencyinjection).

### Enums

`[StringEnum]` makes an enum read and write the same wire name (`PendingApproval` is `pending_approval`) in JSON, ASP.NET Core binding, OpenAPI, EF Core and outgoing HTTP. A source generator writes the helpers, so it works with Native AOT.

```csharp
[StringEnum]
public enum OrderStatus { Pending, PendingApproval, [EnumFallback] Unknown = 99 }

string wire = OrderStatus.PendingApproval.ToWireName(); // "pending_approval"
```

Setup per layer, `[Flags]` rules and the diagnostics are in the [Enums Readme](/libraries/enums). [Examples.Enums.EndToEnd](/examples/enums-endtoend) wires every layer in one app.

## Upgrading

- 8.x to 9.0: [v8-to-v9.md](/migration/v8-to-v9). `default(Result)` is now a failure, `Error.Exception` gives `Unexpected`, and `ErrorType.Domain` maps to 422.
- 7.x to 8.0 with `CSharpEssentials.Core`: [Upgrading to 8.0](/libraries/core#upgrading-to-80). Short GUID strings use the RFC 4648 base64url alphabet, so IDs stored by 7.x need a one-time `-`/`_` swap.
- 6.x to 7.0 with idempotency: [v6-to-v7-idempotency.md](/migration/v6-to-v7-idempotency).
- 6.4 async names: [v6-async-naming.md](/migration/v6-async-naming).
