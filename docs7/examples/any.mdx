---
title: "CSharpEssentials.Any example"
---

A console app that shows the discriminated unions from `CSharpEssentials.Any`. It needs no external services.

## Run

```bash
cd examples/Examples.Any
dotnet run
```

## What each part shows

1. Creating a union by implicit conversion, with `Second(...)` and with `Any.Create`.
2. `Match` (returns `AnyActionResult<TResult>`) and `Switch` (returns `AnyActionStatus`), plus the `NotExecuted` status when the active branch has no handler.
3. `IsSecond` and `GetSecond()`, and the exception from a getter on the wrong branch.
4. `Is`, `As` and `TryAs`, including `As<int>` returning `0` on a mismatch.
5. `Deconstruct` and `ToTuple`.
6. A four-branch union, `Any<string, int, bool, Guid>`.
7. A service method that returns `Any<Order, InvalidQuantity, NotFound>` and maps each branch to a response.
8. `Partition` and `Traverse`.
9. A JSON round trip.
