---
title: "CSharpEssentials.Rules example"
---

A console app that checks car rental applicants with `CSharpEssentials.Rules`. It needs no external services.

## Run

```bash
cd examples/Examples.Rules
dotnet run
```

## What each part shows

1. The three ways to write a rule: a class (`MinimumAgeRule`), a `Func` and `RuleEngine.FromPredicate`.
2. `.And()`: all rules must pass and evaluation stops at the first failure.
3. `.Or()`: one rule must pass. When all fail, every error is returned.
4. `.Linear()` and `.Next()`, plus the `EMPTY_RULE_ARRAY` error for an empty array.
5. The static `RuleEngine.And`, `RuleEngine.Or` and `RuleEngine.Linear` shortcuts.
6. `RuleEngine.If` with a rule, a `bool` and three `Func` arguments.
7. Rules that return a value: `Or` returns the first success, `And` collects all errors or returns the first value.
8. Async rules (`FromPredicateAsync`, a converted `Func`, a class implementing `IAsyncRule`) evaluated with `RuleEngine.EvaluateAsync`.
9. A throwing rule turned into an `Unexpected` error.
10. A custom `ILinearRule` that runs its `Next` rule only on success.
