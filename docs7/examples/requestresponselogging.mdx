---
title: "CSharpEssentials.RequestResponseLogging example"
---

An MVC and Minimal API app that logs requests and responses with [CSharpEssentials.RequestResponseLogging](/libraries/requestresponselogging). Running it sends a request to each endpoint and exits; the log entries are the output.

## Run

```bash
cd examples/Examples.RequestResponseLogging
dotnet run              # tour, then exits
dotnet run -- --serve   # keeps the app running on http://localhost:5000
```

## Setup in `Program.cs`

```csharp
app.UseRouting();                                   // before the middleware, so the skip attributes are seen
app.AddRequestResponseLogging(opt =>
{
    LoggingOptions logging = LoggingOptions.CreateAllFields();
    logging.HeaderKeys.Add(HeaderNames.AcceptLanguage);
    opt.UseLogger(loggerFactory, logging);          // multi-line entry, category RequestResponseLogger
    opt.UseHandler(context => StructuredJsonLogWriter.WriteAsync(context, httpLogger));   // one JSON line, category Http
    opt.IgnorePaths("/health");
});
```

`UseLogger` and `UseHandler` both run, so each request produces two entries. `Infrastructure/StructuredJsonLogWriter.cs` turns a `RequestResponseContext` into compact JSON and cuts bodies at 1000 characters.

## What each request shows

| Request | Shows |
|---|---|
| `GET /api/demo/hello?lang=en` | `Request: Empty request body`, `RequestLength: 18`, the query string |
| `POST /api/demo/echo` with `Accept-Language: tr` | Request body and `Headers: [{"Accept-Language":"tr"}]` |
| `GET /api/demo/notfound` | A problem response body from `ToActionResult` |
| `GET /api/demo/error` | `Response: Exception: InvalidOperationException, Message: Something went wrong.`; the exception is rethrown and `GlobalExceptionHandler` answers 500 |
| `GET /api/demo/slow` | `ResponseTiming` of about 300 ms |
| `POST /api/demo/login` | `[SkipRequestLogging]`: `Request: Skipped logging request body` |
| `GET /api/demo/export` | `[SkipResponseLogging]` on an MVC action |
| `POST /api/demo/secret` | `[SkipRequestResponseLogging]`: both bodies skipped |
| `GET /minimal/export` | `.WithMetadata(new SkipResponseLoggingAttribute())` on a Minimal API endpoint |
| `GET /health` | `IgnorePaths`: no entry |
