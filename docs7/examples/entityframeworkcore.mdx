title: "Examples.EntityFrameworkCore"
---

A console app for `CSharpEssentials.EntityFrameworkCore`. It runs on an in-memory SQLite database, so it needs no server and leaves no file behind.

```bash
cd examples/Examples.EntityFrameworkCore
dotnet run
```

## Files

| File | Shows |
|---|---|
| `Data/ShopDbContext.cs` | `BaseDbContext` with `InterceptorsFromServices => DbContextInterceptors.All`, `ConfigureEnumConventions`, `ConfigureNullableMaybeConventions` and `ApplyNamedSoftDeleteQueryFilter` |
| `Data/Configurations/ProductConfiguration.cs` | `SoftDeletableEntityBaseGuidIdMap()`, `EntityBaseGuidIdMap()` and a unique index |
| `Data/Entities/Product.cs` | `Product : SoftDeletableEntityBase<Guid>` that raises events, and the `[StringEnum]` enum `ProductCategory` |
| `Data/Entities/Customer.cs` | `Customer : EntityBase<Guid>` with a `Maybe<string>?` column |
| `Data/Events/` | `ProductCreatedEvent` (`BeforeSave`) and `ProductPriceChangedEvent` (a `DomainEvent` record, `AfterSave`) |
| `Services/ConsoleDomainEventPublisher.cs` | an `IDomainEventPublisher` that prints each event |
| `Services/SqliteUniqueTranslator.cs` | an `IDbErrorTranslator` for SQLite, which reports no SQLSTATE |
| `Program.cs` | registration and the seven steps below |

## Steps

1. Audit fields and domain events. Saving products stamps `CreatedBy`/`UpdatedBy` and `DomainEventInterceptor` publishes the events.
2. Soft delete. `Remove` becomes a soft delete; `IgnoreSoftDeleteQueryFilter()` shows the deleted row; `Restore()` brings it back; `SoftDeleteAsync` deletes a category in one `UPDATE`.
3. Pagination. `PaginateAsync` reads page 2 by offset, `KeysetPaginateAsync` reads page 2 by cursor, and a tampered cursor returns `KeysetPagination.InvalidCursor`.
4. Result helpers. `FirstOrDefaultAsResultAsync` returns a value or a custom `NotFound` error. `HardDelete` removes a row for real.
5. Columns. The enum is stored as `home_and_garden`; a missing nickname is stored as `NULL` and queried with `== null`.
6. Transactions. `ITransactionRunner` commits one unit (its after-commit callback runs) and rolls back another.
7. Error translation. A duplicate email becomes `Conflict` with the code `Database.UniqueViolation`.

The outbox, the migrations health check, the hosted outbox relay and the distributed lock are in [Examples.EntityFrameworkCore.Operations](https://github.com/senrecep/CSharpEssentials/blob/main/examples/Examples.EntityFrameworkCore.Operations). The [package README](/libraries/entityframeworkcore) covers every feature.

The csproj sets `CentralPackageTransitivePinningEnabled` to `false` because the repository pins EF Core 9 centrally while the libraries use EF Core 10 on `net10.0`. A normal app that installs the NuGet packages does not need this.
