---

A console app for `CSharpEssentials.Entity`. It needs no database.

```bash
cd examples/Examples.Entity
dotnet run
```

The program prints five numbered steps:

1. `Order : EntityBase<Guid>` sets its `Id` in a factory method. `SetCreatedInfo` and `SetUpdatedInfo` fill the audit fields.
2. `Raise` collects an `OrderPlaced` event and an `OrderTotalChanged` event marked `[DomainEventTiming(DomainEventTiming.BeforeSave)]`. The program copies `DomainEvents`, clears the list and prints each event with its timing.
3. `OrderPlaced` derives from the `DomainEvent` record. With a fixed `TimeProvider`, `OccurredAt` is known and `EventId` is a version 7 GUID.
4. `Product : SoftDeletableEntityBase<int>` goes through `MarkAsDeleted`, `Restore` and the `HardDelete()` extension.
5. A helper that takes `ICreationAudit` works with both entity types.

In a real app the EF Core package fills the audit fields and dispatches the events. See [Examples.EntityFrameworkCore](https://github.com/senrecep/CSharpEssentials/blob/main/examples/Examples.EntityFrameworkCore) and the [package README](/libraries/entity).
