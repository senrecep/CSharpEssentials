---
title: "CSharpEssentials.Validation example"
---

A console app that validates users and orders with `CSharpEssentials.Validation`. It needs no external services.

## Run

```bash
cd examples/Examples.Validation
dotnet run
```

## What each part shows

1. A `Validator<T>` class with string, comparable, enum and collection rules, run on a valid and an invalid command.
2. `Validator.ValidateAsync` with an inline delegate.
3. `Cascade(CascadeMode.Continue)` collecting every password error.
4. `Must` with a custom code, `Must` with the generated code, and `MustAsync`.
5. `SetValidatorAsync` for a nested address, `ForEach` over order lines and plain `if` conditions.
6. `Include` to reuse another validator, and an `Order` override.
7. A custom rule (`Even`), `rules.For(value, name)` and `AddFailure`.
8. `ValidateWith` and `ValidateWithAsync` on a `Result<T>`, including a failed source result that skips validation.
9. Reading the `field` metadata from a built-in error.
10. `AddValidator` registration and how a repeated call does not add a duplicate.
11. The remaining built-in rules (`StartsWith`, `Contains`, `ExclusiveBetween`, `Null`, `CountBetween`, `HasOnlyDefinedFlags`, `IsOneOf` and others) and `ForEachAsync`.
12. `AddValidatorsFromAssemblies` scanning the example assembly.
