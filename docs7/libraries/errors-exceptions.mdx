`DomainException` and `EnhancedValidationException` carry `Error` values, for code that has to throw but whose caller works with errors. Both are in the `CSharpEssentials.Exceptions` namespace of the `CSharpEssentials.Errors` package.

```bash
dotnet add package CSharpEssentials.Errors
```

```csharp
using CSharpEssentials.Errors;
using CSharpEssentials.Exceptions;
```

| Type | Constructor | Property | `Message` |
|---|---|---|---|
| `DomainException` | `(Error error)` | `Error` | the error's `Description` |
| `EnhancedValidationException` | `(Error[] errors)`, `null` throws `ArgumentNullException` | `Errors` | `Validation failed with {n} errors` |

## Example

Catch the exception at the boundary and return its errors as a `Result`. `Error` and `Error[]` convert implicitly to `Result<T>` (from `CSharpEssentials.Results`).

```csharp Program.cs
// dotnet add package CSharpEssentials.Errors
// dotnet add package CSharpEssentials.Results
using CSharpEssentials.Errors;
using CSharpEssentials.Exceptions;
using CSharpEssentials.ResultPattern;

Print(CreateUser("ada@example.com", "s3cret!pass"));   // created ada@example.com
Print(CreateUser("not-an-email", "s3cret!pass"));      // INVALID_EMAIL
Print(CreateUser("ada@example.com", "short"));         // PASSWORD_LENGTH, PASSWORD_COMPLEXITY

try
{
    throw new EnhancedValidationException([Error.Validation("A", "a"), Error.Validation("B", "b")]);
}
catch (EnhancedValidationException ex)
{
    Console.WriteLine(ex.Message);                      // Validation failed with 2 errors
}

static Result<User> CreateUser(string email, string password)
{
    try
    {
        if (!email.Contains('@'))
            throw new DomainException(Error.Validation("INVALID_EMAIL", "Email format is not valid."));

        if (password.Length < 8)
            throw new EnhancedValidationException(
            [
                Error.Validation("PASSWORD_LENGTH", "Password must be at least 8 characters."),
                Error.Validation("PASSWORD_COMPLEXITY", "Password must contain a special character."),
            ]);

        return new User(email);
    }
    catch (DomainException ex)
    {
        return ex.Error;
    }
    catch (EnhancedValidationException ex)
    {
        return ex.Errors;
    }
}

static void Print(Result<User> result) =>
    Console.WriteLine(result.Match(
        onSuccess: user => $"created {user.Email}",
        onError: errors => string.Join(", ", errors.Select(e => e.Code))));

public sealed record User(string Email);
```

## ASP.NET Core

With `CSharpEssentials.AspNetCore`, the global exception handler (`DefaultExceptionProblemMapper`) turns either exception into a problem details response built from its errors, with the HTTP status of their `ErrorType`.

Prefer returning a `Result` over throwing. These exceptions are for places where throwing is the only option, such as a constructor or a third-party callback.
