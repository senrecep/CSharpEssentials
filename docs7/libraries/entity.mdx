---
title: "CSharpEssentials.Entity"
---

Base classes for DDD entities: a typed id, audit fields, soft delete and a list of domain events. Use it for the aggregate roots of a domain model. `CSharpEssentials.EntityFrameworkCore` reads these types to fill the audit fields, turn deletes into soft deletes and dispatch the events on save.

## Install

```bash
dotnet add package CSharpEssentials.Entity
```

Targets `net11.0`, `net10.0`, `net9.0` and `netstandard2.1`. Depends on `CSharpEssentials.Results` and `CSharpEssentials.Time`.

## Quick start

```csharp Program.cs
// dotnet add package CSharpEssentials.Entity
using CSharpEssentials.Entity;
using CSharpEssentials.Entity.Interfaces;

Order order = Order.Place("customer-1", 120m);
order.SetCreatedInfo(DateTimeOffset.UtcNow, "alice");

// Copy the events before you clear them: DomainEvents is a live view.
IDomainEvent[] events = [.. order.DomainEvents];
order.ClearDomainEvents();

foreach (IDomainEvent e in events)
    Console.WriteLine(e);                                   // OrderPlaced { EventId = ..., OccurredAt = ..., OrderId = ... }

order.MarkAsDeleted(DateTimeOffset.UtcNow, "alice");
Console.WriteLine($"Deleted: {order.IsDeleted} by {order.DeletedBy}");   // Deleted: True by alice

order.Restore();
Console.WriteLine($"Deleted after restore: {order.IsDeleted}");          // False

public sealed record OrderPlaced(Guid OrderId) : DomainEvent;

public sealed class Order : SoftDeletableEntityBase<Guid>
{
    private Order() { }

    public string CustomerId { get; private set; } = "";
    public decimal Total { get; private set; }

    public static Order Place(string customerId, decimal total)
    {
        Order order = new() { Id = Guid.NewGuid(), CustomerId = customerId, Total = total };
        order.Raise(new OrderPlaced(order.Id));
        return order;
    }
}
```

## Base classes

| Class | Adds |
|---|---|
| `EntityBase` | Audit fields and domain events. No id. |
| `EntityBase<TId>` | `EntityBase` plus `TId? Id { get; protected set; }`. `TId` must implement `IEquatable<TId>`. |
| `SoftDeletableEntityBase` | `EntityBase` plus soft delete. |
| `SoftDeletableEntityBase<TId>` | `SoftDeletableEntityBase` plus `Id`. |

`Id` has a protected setter. Set it in a constructor or a factory method of the derived class.

## Audit fields

Every base class has `CreatedAt`, `CreatedBy`, `UpdatedAt` and `UpdatedBy`. The setters are private, so you set them through two methods:

```csharp
order.SetCreatedInfo(DateTimeOffset.UtcNow, "alice");   // CreatedAt, CreatedBy
order.SetUpdatedInfo(DateTimeOffset.UtcNow, "bob");     // UpdatedAt, UpdatedBy
```

- `CreatedAt` is a `DateTimeOffset`. `SetCreatedInfo` throws `ArgumentOutOfRangeException` for `DateTimeOffset.MinValue`.
- `UpdatedAt` and `UpdatedBy` are `null` until the first `SetUpdatedInfo`.
- The fields are named `UpdatedAt`/`UpdatedBy`, not `ModifiedAt`/`ModifiedBy`.
- With EF Core, `AuditInterceptor` calls these methods on save. You rarely call them yourself.

## Soft delete

`SoftDeletableEntityBase` and `SoftDeletableEntityBase<TId>` add `IsDeleted`, `DeletedAt`, `DeletedBy` and `IsHardDeleted`:

```csharp
product.MarkAsDeleted(DateTimeOffset.UtcNow, "alice");   // IsDeleted = true, DeletedAt, DeletedBy
product.Restore();                                      // clears IsDeleted, DeletedAt, DeletedBy and IsHardDeleted
product.MarkAsHardDeleted();                            // IsHardDeleted = true
products.HardDelete();                                  // MarkAsHardDeleted on every item of an IEnumerable<T> where T : ISoftDeletable
```

`MarkAsDeleted` takes two arguments, the time and the user. `IsHardDeleted` tells the EF Core `AuditInterceptor` to remove the row instead of turning the delete into a soft delete. On its own the flag changes nothing else.

## Domain events

An entity collects events with `Raise` and exposes them through `DomainEvents`:

```csharp
public sealed record PriceChanged(Guid ProductId, decimal NewPrice) : IDomainEvent;

public sealed class Product : EntityBase<Guid>
{
    public decimal Price { get; private set; }

    public void ChangePrice(decimal price)
    {
        Price = price;
        Raise(new PriceChanged(Id, price));
    }
}
```

- `Raise(IDomainEvent)` adds an event. It throws `ArgumentNullException` for `null`.
- `DomainEvents` is an `IReadOnlyList<IDomainEvent>` property. It is a live view of the internal list, not a copy, so reading it does not allocate.
- `ClearDomainEvents()` empties the list.
- Raising or clearing while you loop over `DomainEvents` throws `InvalidOperationException`. A reference you keep also shows later changes. Copy first: `IDomainEvent[] events = [.. entity.DomainEvents];`.
- Call `Raise` from methods of the entity, so the aggregate decides which events happen.

## The DomainEvent record

`IDomainEvent` is an empty marker interface. Derive from the `DomainEvent` record when the event needs an id and a time, for example because an outbox stores it:

```csharp Program.cs
// dotnet add package CSharpEssentials.Entity
using CSharpEssentials.Entity;

OrderShipped shipped = new(Guid.NewGuid(), new FixedClock(new DateTimeOffset(2026, 1, 15, 9, 30, 0, TimeSpan.Zero)));
Console.WriteLine(shipped.OccurredAt);                     // 15/01/2026 09:30:00 +00:00 (culture dependent)
Console.WriteLine(shipped.EventId.ToString()[14]);         // 7: a version 7 GUID

OrderPlaced placed = new(Guid.NewGuid());                  // reads TimeProvider.System
Console.WriteLine(placed.OccurredAt > shipped.OccurredAt); // True

public sealed record OrderPlaced(Guid OrderId) : DomainEvent;

public sealed record OrderShipped : DomainEvent
{
    public OrderShipped(Guid orderId, TimeProvider clock) : base(clock) => OrderId = orderId;

    public Guid OrderId { get; init; }
}

public sealed class FixedClock(DateTimeOffset now) : TimeProvider
{
    public override DateTimeOffset GetUtcNow() => now;
}
```

- `OccurredAt` is the current time of `TimeProvider.System`, or of the `TimeProvider` passed to `base(clock)`. A fake clock gives a known value in tests.
- `EventId` is `Guider.NewGuid(OccurredAt)`, a version 7 GUID, so ids sort by creation time.
- Both properties are `init`, so System.Text.Json restores the stored values when it reads an event back.
- `DomainEvent` implements `IIdentifiedDomainEvent`. The EF Core outbox uses `EventId` as the message id and `OccurredAt` as the delivery order.
- If your code also has a type named `DomainEvent`, a file that imports both namespaces fails with CS0104. Qualify the name or add an alias.

## Event timing

`[DomainEventTiming]` labels when an event is dispatched relative to `SaveChanges`. Without the attribute the timing is `AfterSave`.

```csharp
public sealed record OrderPlaced(Guid OrderId) : IDomainEvent;              // AfterSave (default)

[DomainEventTiming(DomainEventTiming.BeforeSave)]
public sealed record StockReserved(Guid ProductId, int Quantity) : IDomainEvent;
```

| Timing | Use for | Dispatch |
|---|---|---|
| `AfterSave` | notifications, projections, integration events | `BaseDbContext` publishes after the save succeeds. `DomainEventInterceptor` handles them before the write, so an outbox can store them in the same save. |
| `BeforeSave` | validation or changes that belong to the same transaction | published before the write. A handler that throws aborts the save. |

The attribute only labels the class (it is not inherited). `CSharpEssentials.EntityFrameworkCore` reads it.

## Interfaces

All in `CSharpEssentials.Entity.Interfaces`. Use them to write code that works with any entity.

| Interface | Members |
|---|---|
| `ICreationAudit` | `CreatedAt`, `CreatedBy`, `SetCreatedInfo` |
| `IModificationAudit` | `UpdatedAt`, `UpdatedBy`, `SetUpdatedInfo` |
| `IDomainEventHolder` | `DomainEvents`, `Raise`, `ClearDomainEvents` |
| `IEntityBase` | `ICreationAudit` + `IModificationAudit` + `IDomainEventHolder` |
| `IEntityBase<TId>` | `IEntityBase` + `Id` |
| `ISoftDeletableBase` | `IsDeleted` |
| `ISoftDeletable` | `ISoftDeletableBase` + `DeletedAt`, `DeletedBy`, `IsHardDeleted`, `MarkAsDeleted`, `Restore`, `MarkAsHardDeleted` |
| `ISoftDeletableEntityBase`, `ISoftDeletableEntityBase<TId>` | `IEntityBase` (or `IEntityBase<TId>`) + `ISoftDeletable`; implemented by the soft-deletable base classes |
| `IDeletableEntityBase`, `IDeletableEntityBase<TId>` | the same combination; no base class implements it |
| `IDomainEvent` | marker for events |
| `IIdentifiedDomainEvent` | `IDomainEvent` + `EventId`, `OccurredAt` |

The EF Core query filters look for `ISoftDeletableBase`. The audit interceptor looks for `ICreationAudit`, `IModificationAudit` and `ISoftDeletable`, so a class of your own that implements them works without the base classes.
