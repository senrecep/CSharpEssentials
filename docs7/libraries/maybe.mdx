---
title: "CSharpEssentials.Maybe"
---

`Maybe<T>` is an option type: it either holds a value or is `None`. Use it inside your code where a missing value is a normal case, so callers have to handle it instead of meeting a `null` at run time.

```bash
dotnet add package CSharpEssentials.Maybe
```

Targets `net11.0`, `net10.0`, `net9.0` and `netstandard2.1`. Depends on `CSharpEssentials.Results` and `CSharpEssentials.Errors`. `Maybe<T>`, the non-generic `Maybe` helper and all extension methods live in the `CSharpEssentials.Maybe` namespace.

## Quick start

```csharp Program.cs
// dotnet add package CSharpEssentials.Maybe
using CSharpEssentials.Errors;
using CSharpEssentials.Maybe;
using CSharpEssentials.ResultPattern;

Dictionary<int, User> users = new()
{
    [1] = new User(1, "Ada", "ada@example.com"),
    [2] = new User(2, "Bo", null),
};

Maybe<User> FindUser(int id) => users.TryGetValue(id, out User? user) ? user : Maybe.None;

foreach (int id in new[] { 1, 2, 3 })
{
    string email = FindUser(id)
        .Bind(u => Maybe.From(u.Email))
        .Map(e => e.ToLowerInvariant())
        .GetValueOrDefault("no email");
    Console.WriteLine($"{id}: {email}");
}

Result<User> result = FindUser(3).ToResult(Error.NotFound("User.NotFound", "User 3 does not exist."));
Console.WriteLine(result.IsFailure ? result.FirstError.Description : result.Value.Name);

internal sealed record User(int Id, string Name, string? Email);
```

Output:

```text
1: ada@example.com
2: no email
3: no email
User 3 does not exist.
```

## Creating a Maybe

```csharp
Maybe<int> some = 42;                                     // implicit from T
Maybe<string> fromNull = (string?)null;                   // null becomes None
Maybe<string> none = Maybe.None;                          // converts to any Maybe<T>
Maybe<string> name = Maybe.From("Ann");                   // From infers T
Maybe<int> five = 5.AsMaybe();                            // extension on any T?
Maybe<string> home = Maybe.From(() => Environment.GetEnvironmentVariable("HOME"));
Maybe<int> parsed = Maybe.FromTry(() => int.Parse("abc")); // None, the exception is swallowed
Maybe<int> generic = Maybe<int>.None;                     // the same factories exist on Maybe<T>
```

- `From(null)` and the implicit conversion from `null` give `None`. A bare `Maybe.From(null)` does not compile because `T` cannot be inferred.
- `FromTry` returns `None` when the factory throws, except for `OperationCanceledException`, which it rethrows.
- `Maybe.FromAsync(task)` and `Maybe.FromAsync(() => task)` await a `Task<T?>`.

## Reading the value

```csharp
Maybe<int> maybe = 5;

bool has = maybe.HasValue;                         // also HasNoValue
int value = maybe.Value;                           // throws InvalidOperationException on None
int a = maybe.GetValueOrDefault(0);                // fallback value
int? b = maybe.GetValueOrDefault();                // default(T) on None
int c = maybe.GetValueOrDefault(() => 0);          // lazy fallback
int d = maybe.GetValueOrElse(() => 0);             // same as above
int e = maybe.GetValueOrDefault(v => v * 2, -1);   // map when Some, fallback when None
int f = maybe.GetValueOrThrow("missing");          // InvalidOperationException with your message
int g = maybe.GetValueOrThrow(new KeyNotFoundException());
bool found = maybe.TryGetValue(out int h);
var (hasValue, inner) = maybe;                     // Deconstruct
int? i = maybe.AsNullable();                       // default(T) for a value type on None
List<int> list = maybe.ToList();                   // one item or empty
```

`HasValue` carries `[MemberNotNullWhen]`, so after `if (maybe.HasValue)` the compiler knows `Value` is not null.

## Map, Bind and Where

```csharp
Maybe<User> user = new User(1, "Ada", "ada@example.com");

Maybe<string> upper = user.Map(u => u.Name.ToUpperInvariant());   // transform the value
Maybe<string> email = user.Bind(u => Maybe.From(u.Email));        // the next step returns a Maybe
Maybe<User> named = user.Where(u => u.Name.StartsWith('A'));      // None when the predicate fails
```

`Bind` also has an overload that passes a context object without a closure: `user.Bind((u, ctx) => ..., ctx)`.

## LINQ query syntax

`Select`, `SelectMany` and `Where` make query syntax work.

```csharp
Maybe<string> line =
    from u in user
    from mail in Maybe.From(u.Email)
    where mail.Contains('@')
    select $"{u.Name} <{mail}>";
```

## Fallbacks

```csharp
Maybe<int> empty = Maybe<int>.None;

Maybe<int> a = empty.Or(7);                    // a plain T converts to Maybe<T>
Maybe<int> b = empty.Or(() => 8);              // Func<T>, runs only on None
Maybe<int> c = empty.Or(() => Maybe.From(9));  // Func<Maybe<T>>
Maybe<int> d = empty.OrElse(() => 10);         // alias of Or(Func<Maybe<T>>)
```

## Conditional steps

`MapIf`, `BindIf` and `TapIf` run only when there is a value and the condition holds. The condition can be a `bool`, a `Func<bool>` or a `Func<T, bool>`.

```csharp
Maybe<int> score = 42;

Maybe<int> bonus = score.MapIf(v => v > 40, v => v + 10);              // Some(52)
Maybe<int> kept = score.BindIf(false, v => Maybe<int>.None);           // Some(42), not run
score.TapIf(v => v > 40, v => Console.WriteLine($"high score {v}"));
```

## Match

```csharp
string label = user.Match(some: u => u.Name, none: () => "stranger");

user.Match(
    some: u => Console.WriteLine($"found {u.Name}"),
    none: () => Console.WriteLine("not found"));
```

A context overload exists here too: `Match((u, ctx) => ..., ctx => ..., ctx)`. On a `Maybe<KeyValuePair<TKey, TValue>>`, `Match` hands you the key and value separately: `pair.Match(some: (key, value) => ..., none: () => ...)`.

## Side effects

All of these return the same `Maybe<T>`, except `Execute` and `ExecuteNoValue`, which return nothing.

```csharp
Maybe<int> maybe = 5;

maybe.Tap(v => Console.WriteLine(v));                // on Some
maybe.Tap(() => Console.WriteLine("has a value"));   // on Some, no argument
maybe.TapNone(() => Console.WriteLine("missing"));   // on None
maybe.Execute(v => Console.WriteLine(v));            // on Some
maybe.ExecuteNoValue(() => Console.WriteLine("none"));
```

## Converting to Result

```csharp
Maybe<User> user = Maybe.None;

Result<User> withError = user.ToResult(Error.NotFound("User.NotFound", "User not found."));
Result<User> defaultError = user.ToMaybeResult();   // Error.NotFound with code "Maybe.Result"
Result unit = user.ToUnitResult();                  // success or failure, no value
```

- Always pass an `Error` to `ToResult`. `maybe.ToResult()` with no argument binds the generic `ToResult<TValue>(this TValue value)` from `CSharpEssentials.Results` and returns a successful `Result<Maybe<T>>`. Call `ToMaybeResult()` when you want the default error.
- `ToResult(error)` and `ToUnitResult(error)` are the same as `ToMaybeResult(error)` and `ToMaybeUnitResult(error)`.
- With a typed error, `maybe.ToResult(new UserMissing(3))` returns `Result<T, UserMissing>`.

## Converting from Result

```csharp
Result<int> ok = 5;
Maybe<int> some = ok.AsMaybe();      // Some(5)

Result<int> failed = Error.Validation("X", "bad");
Maybe<int> none = failed.AsMaybe();  // None, the errors are dropped
```

`AsMaybe` also works on the typed results `Result<T, E1>`, `Result<T, E1, E2>` and `Result<T, E1, E2, E3>`. An error gives `None`. A `default` typed result throws `InvalidOperationException`.

## Collections

```csharp
int[] numbers = [3, 8, 11];
Maybe<int> firstEven = numbers.TryFirst(n => n % 2 == 0);   // Some(8)
Maybe<int> last = numbers.TryLast();                        // Some(11)
Maybe<int> nothing = Array.Empty<int>().TryFirst();         // None, also for value types

IReadOnlyDictionary<string, int> stock = new Dictionary<string, int> { ["apple"] = 3 };
Maybe<int> apples = stock.TryFind("apple");                 // Some(3)

Maybe<int>[] maybes = [1, Maybe.None, 3];
IEnumerable<int> present = maybes.Choose();                 // 1, 3
IEnumerable<int> scaled = maybes.Choose(v => v * 10);       // 10, 30
var (values, noneCount) = maybes.Partition();               // [1, 3], 1
Maybe<int[]> all = maybes.Sequence();                       // None, one item is missing
Maybe<int[]> parsed = new[] { "1", "2" }.Traverse(s => Maybe.FromTry(() => int.Parse(s)));  // Some([1, 2])

Maybe<int> flat = Maybe<Maybe<int>>.From(Maybe<int>.From(5)).Flatten();  // Some(5)
Maybe<int>? stored = null;
Maybe<int> fromNullable = stored.Flatten();                              // None
```

| Method | Returns | When an item is missing |
|---|---|---|
| `Sequence()` | `Maybe<T[]>` | the whole result is `None` |
| `Traverse(selector)` | `Maybe<TOut[]>` | the whole result is `None` |
| `Partition()` | `(T[] Values, int NoneCount)` | counted in `NoneCount` |
| `Choose()`, `Choose(selector)` | `IEnumerable<T>` | skipped |
| `ChooseAsync()` | `IAsyncEnumerable<T>` | skipped |

- `TryFirst` and `TryLast` return `None` for an empty sequence, for no match and for a `null` element.
- On an `IList<T>` or `IReadOnlyList<T>`, `TryLast` reads by index and `TryLast(predicate)` walks backwards from the end.
- On .NET 9 and later, `ChooseAsync` uses `Task.WhenEach`, so values come out in completion order, not source order. On `netstandard2.1` it awaits in source order.

## Async

Every member that returns a `Task` or `ValueTask` ends in `Async`. Instance methods work on a `Maybe<T>`, and extension methods continue a `Task<Maybe<T>>` or `ValueTask<Maybe<T>>`, so a chain needs a single `await`.

```csharp Program.cs
// dotnet add package CSharpEssentials.Maybe
using CSharpEssentials.Errors;
using CSharpEssentials.Maybe;
using CSharpEssentials.ResultPattern;

Maybe<User> user = await Maybe.FromAsync(LoadUserAsync(1));

Maybe<string> name = await user.MapAsync(u => Task.FromResult(u.Name));

Maybe<User> guest = await Maybe.FromAsync(LoadUserAsync(9))
    .OrAsync(() => new User(0, "Guest"));

string text = await user.MatchAsync(
    some: (u, ct) => Task.FromResult($"found {u.Name}"),
    none: ct => Task.FromResult("missing"));

Result<User> result = await Maybe.FromAsync(LoadUserAsync(9))
    .ToResultAsync(Error.NotFound("User.NotFound", "User not found."));

Console.WriteLine($"{name} | {guest.Value.Name} | {text} | {result.FirstError.Code}");

static async Task<User?> LoadUserAsync(int id)
{
    await Task.Yield();
    return id == 1 ? new User(1, "Ada") : null;
}

internal sealed record User(int Id, string Name);
```

The async family: `FromAsync`, `MapAsync`, `BindAsync`, `WhereAsync`, `OrAsync`, `OrElseAsync`, `MatchAsync`, `TapAsync`, `TapIfAsync`, `TapNoneAsync`, `MapIfAsync`, `BindIfAsync`, `ExecuteAsync`, `ExecuteNoValueAsync`, `GetValueOrDefaultAsync`, `GetValueOrThrowAsync`, `ToResultAsync`, `ToUnitResultAsync`, `ToMaybeResultAsync`, `ToMaybeUnitResultAsync` and `AsMaybeAsync`. Most take an optional `CancellationToken`.

- Async `Match` handlers receive the token: `some: (value, ct) => ...`, `none: ct => ...`.
- `maybe.MapAsync(async v => ...)` is ambiguous (CS0121) because the instance `MapAsync` has a `Task` and a `ValueTask` overload. Pass a lambda that returns a `Task` directly (`v => LoadAsync(v)`) or type the delegate.
- An untyped async lambda on the instance `ExecuteAsync`, `ExecuteNoValueAsync`, `OrAsync`, `WhereAsync` or `MatchAsync` picks the `Task` overload through `OverloadResolutionPriority`, which needs C# 13 or later. On C# 12, type the lambda.
- The unsuffixed overloads that return a `Task` or `ValueTask` are `[Obsolete]`: `Execute`, `ExecuteNoValue`, `Or`, `Where` and `Match` with async arguments or on a `Task<Maybe<T>>`, `Maybe.From(Task)`, and `ToMaybeResult`/`ToMaybeUnitResult` on a `Task<Maybe<T>>`. Use the `Async` names.
- Cancelling the token while an operation waits throws `TaskCanceledException` (an `OperationCanceledException`).

## Equality

- `Maybe<int>.From(0) == 0` is `true`. `Maybe<int>.None == 0` is `false`.
- `Maybe<string>.None == null` is `true`, in either operand order.
- `None.Equals((object?)null)` is `false`, following the BCL rule. Test for absence with `HasNoValue`.
- For a value type, `maybe == default` compares with `default(T)`, and `Maybe<int> == null` does not compile cleanly (CS9342). Use `HasNoValue`.
- Two `None` values are equal. `GetHashCode()` of `None` is `0`.

## ToString and JSON

`ToString()` returns `Some(value)` or `None`. `IFormattable` values use the invariant culture.

`System.Text.Json` writes `{"HasValue":true,"value":5}` and reads the same shape back. A `null` value or `HasValue: false` reads back as `None`.

## IMaybe

`Maybe<T>` implements `IMaybe<T>` from the `CSharpEssentials.Maybe.Interfaces` namespace, and the non-generic `Maybe` implements `IMaybe`. Use them to detect a `Maybe` in generic code. `IMaybe<T>` exposes `Value`, `HasValue`, `HasNoValue` and the core members.

## T?, Maybe<T> or Result<T>

| Use | When |
|---|---|
| `T?` | At boundaries: DTOs, entity columns, JSON contracts |
| `Maybe<T>` | Inside the domain, when absence is expected and you compose with `Map` and `Bind` |
| `Result<T>` | When the caller needs to know why the value is missing |
