title: "CSharpEssentials.GcpSecretManager"
---

A configuration provider that loads Google Cloud Secret Manager secrets into `IConfiguration` at startup. Use it when an app on .NET reads its connection strings, API keys and other secrets from Secret Manager and should see them as ordinary configuration keys.

## Install

```bash
dotnet add package CSharpEssentials.GcpSecretManager
```

```csharp
using CSharpEssentials.GcpSecretManager;               // ProjectSecretConfiguration
using CSharpEssentials.GcpSecretManager.Configuration; // SecretManagerConfigurationOptions, ISecretManagerConfigurationLoader
using CSharpEssentials.GcpSecretManager.Extensions;    // AddGcpSecretManager
```

## Quick start

```csharp Program.cs
// dotnet add package CSharpEssentials.GcpSecretManager
// build-only: needs Google Cloud credentials and a project with secrets
using CSharpEssentials.GcpSecretManager;
using CSharpEssentials.GcpSecretManager.Extensions;
using Microsoft.Extensions.Configuration;

// builder.Configuration in a web or worker app is a ConfigurationManager too.
var configuration = new ConfigurationManager();

configuration.AddGcpSecretManager(options =>
{
    options.AddProject(new ProjectSecretConfiguration
    {
        ProjectId = "my-gcp-project",
        PrefixFilters = ["MyApp__"],
    });
});

// The secret "MyApp__ConnectionStrings__Default" is now this key:
Console.WriteLine(configuration["MyApp:ConnectionStrings:Default"]);
```

`AddGcpSecretManager` extends `IConfigurationManager`, which is `builder.Configuration` of a `WebApplicationBuilder` or `HostApplicationBuilder`. It is not available on a plain `IConfigurationBuilder`.

Secrets are loaded once, synchronously, inside the `AddGcpSecretManager` call. There is no reload. The client uses Application Default Credentials (`gcloud auth application-default login` on a workstation, the attached service account on Google Cloud) unless `CredentialsPath` points to a key file. The account needs the Secret Manager Secret Accessor role, plus permission to list secrets.

## Choosing projects and secrets

Add one `ProjectSecretConfiguration` per project with `options.AddProject(...)`. `AddProject` returns the options, so calls chain. At least one project is required; with none, `AddGcpSecretManager` throws `ArgumentException`.

| `ProjectSecretConfiguration` | Meaning |
|---|---|
| `ProjectId` | Required. The Google Cloud project id. |
| `Region` | Optional. Reads the regional secrets of `projects/{id}/locations/{region}` through `secretmanager.{region}.rep.googleapis.com`. |
| `PrefixFilters` | Load secrets whose id starts with one of these prefixes (case-sensitive). |
| `SecretIds` | Also load these secrets by exact id. |
| `RawSecretIds`, `RawSecretPrefixes` | Keep these secrets as one string, without JSON flattening. |

With neither `PrefixFilters` nor `SecretIds`, every secret in the project is loaded. Narrow the list: loading a whole project is slower and needs wider permissions. The `latest` version of each secret is read.

## Options

| `SecretManagerConfigurationOptions` | Default | Meaning |
|---|---|---|
| `Projects` | empty | The projects. Use `AddProject` to add one. |
| `CredentialsPath` | `null` | Path to a service account key file. `null` uses Application Default Credentials. |
| `LoadFromAppSettings` | `true` without a callback, `false` with one | Also read projects from a configuration section. |
| `ConfigurationSectionName` | `"GoogleSecretManager"` | The section `LoadFromAppSettings` reads. |
| `BatchSize` | `10` | Secrets read in parallel per project. Must be greater than 0. |
| `PageSize` | `300` | Secrets per list request. `0` lets the server choose. Must not be negative. |
| `LoggerFactory` | `null` | Logger for diagnostics. Nothing is logged without it. |
| `Loader` | `null` | A custom `ISecretManagerConfigurationLoader`. |

An invalid `BatchSize` or `PageSize` throws `ArgumentOutOfRangeException` as soon as it is set.

## Projects from appsettings.json

Without a callback, `AddGcpSecretManager()` reads the projects from the `GoogleSecretManager` section. Every `ProjectSecretConfiguration` property can be set there.

```json
{
  "GoogleSecretManager": {
    "Projects": [
      { "ProjectId": "my-project", "PrefixFilters": ["Prod__"], "RawSecretIds": ["service-account-json"] }
    ]
  }
}
```

```csharp
builder.Configuration.AddGcpSecretManager();
```

- The section is read from the sources added before the call. `builder.Configuration` already holds `appsettings.json`; with your own `ConfigurationManager`, add the JSON file first.
- A missing section, an empty project list or a project without `ProjectId` throws `InvalidOperationException`.
- With a callback the section is not read. Set `options.LoadFromAppSettings = true` to read it as well, and `options.ConfigurationSectionName` to read another section.

The checks run before Google Cloud is contacted, so they can be tried offline:

```csharp Program.cs
// dotnet add package CSharpEssentials.GcpSecretManager
using CSharpEssentials.GcpSecretManager.Configuration;
using CSharpEssentials.GcpSecretManager.Extensions;
using Microsoft.Extensions.Configuration;

Try("no section", () => new ConfigurationManager().AddGcpSecretManager());
Try("no project", () => new ConfigurationManager().AddGcpSecretManager(options => options.CredentialsPath = null));
Try("bad BatchSize", () => new SecretManagerConfigurationOptions().BatchSize = 0);

var withSection = new ConfigurationManager();
withSection.AddInMemoryCollection(new Dictionary<string, string?> { ["Secrets:Projects:0:PrefixFilters:0"] = "App__" });
Try("no ProjectId", () => withSection.AddGcpSecretManager(options =>
{
    options.LoadFromAppSettings = true;
    options.ConfigurationSectionName = "Secrets";
}));

static void Try(string name, Action action)
{
    try
    {
        action();
        Console.WriteLine($"{name}: no exception");
    }
    catch (Exception ex)
    {
        Console.WriteLine($"{name}: {ex.GetType().Name}: {ex.Message.Split(Environment.NewLine)[0]}");
    }
}
// no section: InvalidOperationException: Configuration section 'GoogleSecretManager' not found in appsettings.json
// no project: ArgumentException: At least one project configuration is required. ...
// bad BatchSize: ArgumentOutOfRangeException: BatchSize must be greater than zero. ...
// no ProjectId: InvalidOperationException: ProjectId is required for each project configuration
```

## Keys and JSON secrets

The secret id becomes the key, with every `__` replaced by `:`. `MyApp__ConnectionStrings__Default` is read as `MyApp:ConnectionStrings:Default`. Keys are case-insensitive, like all .NET configuration. When two secrets or two projects give the same key, ignoring case, the first one wins, with projects in the order you added them.

A secret whose value is a JSON object or array is also flattened. The secret's own key keeps the raw text, and every value inside gets a child key, with `:` between property names and array indexes:

| Secret `MyApp__Database` | Keys |
|---|---|
| `{"Host":"db","Ports":[5432,5433]}` | `MyApp:Database` = the raw JSON, `MyApp:Database:Host` = `db`, `MyApp:Database:Ports:0` = `5432`, `MyApp:Database:Ports:1` = `5433` |

Bind the section as usual, for example `configuration.GetSection("MyApp:Database").Get<DatabaseOptions>()`. A value that is not valid JSON stays a plain string. List a secret in `RawSecretIds`, or match it with `RawSecretPrefixes`, to keep JSON text (a certificate bundle, a service account file) as one value without child keys. `ProjectSecretConfiguration.IsRawSecret(secretId)` tells you which secrets that applies to.

## Custom key mapping and selection

Implement `ISecretManagerConfigurationLoader` and set `options.Loader` to change how ids become keys or which secrets load:

- `GetKey(Secret secret)`: the configuration key for a secret. The provider calls this one.
- `GetKey(string keyId)`: the same for a bare id. The provider does not call it; keep it consistent with the other overload.
- `ShouldLoadSecret(Secret secret, ProjectSecretConfiguration project)`: whether to load a listed secret.

The built-in loader is internal. A custom loader replaces both the `__` mapping and the `PrefixFilters` / `SecretIds` filter, so reimplement the filter if you still want those settings to apply. Raw secrets and JSON flattening still apply.

```csharp Program.cs
// dotnet add package CSharpEssentials.GcpSecretManager
using CSharpEssentials.GcpSecretManager;
using CSharpEssentials.GcpSecretManager.Configuration;
using Google.Cloud.SecretManager.V1;

var project = new ProjectSecretConfiguration
{
    ProjectId = "my-gcp-project",
    PrefixFilters = ["myapp--"],
    RawSecretPrefixes = ["myapp--cert"],
};
var loader = new DashLoader();

foreach (string id in new[] { "myapp--db--password", "myapp--cert--pem", "other--key" })
{
    var secret = new Secret { SecretName = new SecretName(project.ProjectId, id) };
    Console.WriteLine($"{id,-20} load={loader.ShouldLoadSecret(secret, project),-5} key={loader.GetKey(secret),-18} raw={project.IsRawSecret(id)}");
}
// myapp--db--password  load=True  key=myapp:db:password  raw=False
// myapp--cert--pem     load=True  key=myapp:cert:pem     raw=True
// other--key           load=False key=other:key          raw=False

// Use it with: configuration.AddGcpSecretManager(o => { o.Loader = new DashLoader(); o.AddProject(project); });

// Secret ids may not contain ':' or '.', so this loader uses "--" as the separator.
public sealed class DashLoader : ISecretManagerConfigurationLoader
{
    public string GetKey(Secret secret) => GetKey(secret.SecretName.SecretId);

    public string GetKey(string keyId) => keyId.Replace("--", ":");

    public bool ShouldLoadSecret(Secret secret, ProjectSecretConfiguration project)
    {
        string id = secret.SecretName.SecretId;
        bool unfiltered = project.PrefixFilters.Count == 0 && project.SecretIds.Count == 0;
        return unfiltered || project.SecretIds.Contains(id) || project.PrefixFilters.Any(p => id.StartsWith(p, StringComparison.Ordinal));
    }
}
```

## Logging

Configuration providers are built before dependency injection exists, so the provider cannot resolve a logger. Pass an `ILoggerFactory` to see what happens: per-secret progress at `Debug`, failures at `Error`. Without one, a missing permission only shows up as missing keys.

```csharp
// dotnet add package Microsoft.Extensions.Logging.Console
using ILoggerFactory loggerFactory = LoggerFactory.Create(b => b.AddConsole());

builder.Configuration.AddGcpSecretManager(options =>
{
    options.LoggerFactory = loggerFactory;
    options.AddProject(new ProjectSecretConfiguration { ProjectId = "my-gcp-project" });
});
```

## Failures and retries

- Listing secrets and reading each secret are retried on `ResourceExhausted` and `Unavailable` only: 3 retries with exponential backoff (2 s, 4 s, 8 s), through `RetryIfFailed` from [CSharpEssentials.Resilience](https://github.com/senrecep/CSharpEssentials/blob/main/CSharpEssentials.Resilience/Readme.MD). The client library's own retry for secret access is turned off.
- Any other gRPC status, such as `PermissionDenied` or `NotFound`, fails at once.
- A failed read skips that secret. A failed listing, or any non-gRPC exception while loading a project, skips the whole project. The error is logged once at `Error` and loading continues with the other projects, so startup does not fail.
- Creating the client fails when no credentials can be found. That exception is not caught: it comes out of `AddGcpSecretManager`.

## Notes

- Call `AddGcpSecretManager` after the JSON and environment sources, so secrets override local values.
- Name secrets with `__` between levels so they bind to options classes.
- Not Native AOT compatible: Google.Cloud.SecretManager.V1 and the other Google Cloud .NET libraries do not support trimming or Native AOT yet. Trimming them raises IL2026 and IL2104 warnings from Google.Api.Gax.Grpc, Google.Apis.Core, Google.Protobuf and Newtonsoft.Json ([google-cloud-dotnet#13328](https://github.com/googleapis/google-cloud-dotnet/issues/13328)).

## Upgrade notes

From 7.x:

- `BatchSize` must be greater than zero and `PageSize` must not be negative; other values throw when set. Before, a `BatchSize` of zero or less hung startup and a negative `PageSize` loaded nothing.
- Keys are case-insensitive. Before, `database__password` did not match `Database:Password`, and ids that differ only by case gave two keys; now the first one wins.
